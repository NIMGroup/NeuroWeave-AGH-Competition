# ANTs：配准与影像处理注意事项

## 空间与变换

配准将 moving 影像映射到 fixed 参考空间。先明确目标空间、影像对比度、视野和掩膜；同一文件格式或相同矩阵大小并不能证明影像已经对齐。

刚体、仿射和非线性变换允许的形变不同，应依据研究目的选择。检查叠加图、脑边界和局部结构，保留变换及日志；程序退出成功不等于配准质量合格。[ANTs 官方配准说明](https://github.com/ANTsX/ANTs/wiki/Anatomy-of-an-antsRegistration-call)

## 插值与强度

标签图和连续强度图需要不同的插值选择。标签图重采样应避免产生新的小数标签；应用变换时还需要核对方向、顺序和参考影像。[ANTs 官方变换说明](https://github.com/ANTsX/ANTs/wiki/antsApplyTransforms)

N4 校正的是平滑的强度偏置，不能替代空间配准或组织分割。检查校正后的影像和掩膜，保留输入以便比较。

## 当前能力边界

通过 `list_skill_methods` 查询已经接入的操作，再读取对应 Method 的输入、条件参数和产物。这里的说明不增加新的命令、插值选项或变换操作；输出位置、线程和执行环境由当前任务与 Runner 管理。
