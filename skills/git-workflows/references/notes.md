## 历史与协作

重写提交会改变提交标识，协作时需要考虑其他分支和引用。Reflog 可用于定位本地引用的历史位置，但保存时间受仓库配置及清理影响，不能视为永久备份。

定位缺陷时保留可以重复的判定条件；合并冲突解决后检查完整行为，而不仅是消除冲突标记。本文只解释背景，实际操作能力以已登记方法为准。
