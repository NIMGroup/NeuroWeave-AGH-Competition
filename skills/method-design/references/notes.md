# method-design：背景与注意事项

这些资料用于按需解释和排错；当前输入、参数、产物和运行能力以独立 Method/Pipeline 契约为准。

## 方法设计中的可检查内容

方法说明应区分研究假设、已有结果与待验证推断，给出输入、输出、建模假设、损失函数或统计模型，以及评价方案。方程中的变量、维度、单位和适用条件需要一致。

架构图和伪代码有助于检查数据流，但不能证明实现或科研结论正确。引用外部方法时保留出处；符号推导、数值检查和真实实验属于不同证据。

## 来源与归属

由导入的原始说明选取背景、科学限制和解释性内容整理；执行策略与参数以当前 JSON 契约为准。
