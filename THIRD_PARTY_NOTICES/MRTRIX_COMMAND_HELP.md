# MRtrix3 command documentation

The files in `skills/dwi-skill/references/mrtrix-3.0.8/` are command help emitted by
the installed MRtrix3 3.0.8 executables (build June 18, 2026). Command algorithms
are not copied or reimplemented. Only trailing whitespace has been normalized.
Usage snapshots supply upstream option descriptions and typed invocation metadata.

Each Markdown snapshot retains its own author, copyright and license notice.
Those individual notices apply: most refer to Mozilla Public License 2.0;
dwidenoise carries the NYU / University of Antwerp non-commercial research
permission notice, including its exclusion of clinical care. Do not replace
individual command notices with a blanket project license.
